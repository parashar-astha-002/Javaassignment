# Java Programming Assignments

This folder contains 21 separate Java programs covering:
- Basic input/output and arithmetic
- String operations
- Arrays
- Abstract classes
- Interfaces
- Inner classes, static nested classes, and lambda expressions

## How to run
1. Install a JDK.
2. Open a terminal in this folder.
3. Compile a program, for example:
   `javac 01_Arithmetic.java`
4. Run it using the class name:
   `java Arithmetic`

Each source file contains one public class. The filename (without `.java`) matches that public class name.
